> Уровень: углублённое руководство. Сохраните исходные сведения восстановления и файлы кошелька перед изменением настроек восстановления или работы с файлами.

Сначала выполните [обычные проверки восстановления](/ru/backup-recovery/restore/): нужный кошелёк, точные исходные слова и парольная фраза, соединение и ход сканирования. Эта страница описывает конкретные причины, по которым этих проверок может быть недостаточно.

<span id="address-scanning-and-account-compatibility" data-ginger-heading="сканирование-адресов-и-совместимость-аккаунтов" aria-hidden="true"></span>

## Сканирование адресов и совместимость аккаунтов

Экран восстановления принимает действительные наборы английских слов восстановления из 12, 15, 18, 21 или 24 слов и проверяет их контрольную сумму. Одни только действительные слова не устанавливают совместимость аккаунта другого приложения.

Если до оплаченного адреса вы использовали необычно большое количество неиспользованных адресов получения, **Advanced Recovery Options** предлагает **Minimum Gap Limit:**. По умолчанию экран восстановления этой версии использует 114. Повышение может расширить поиск ценой дополнительной работы и времени; оно не исправляет неверные слова, неверную парольную фразу или несовместимый формат кошелька. Используйте большее значение только при наличии оснований в истории адресов.

Кошелёк, первоначально созданный другим приложением, может использовать другие типы адресов, аккаунты или пути деривации. Одни слова BIP39 не гарантируют, что каждый кошелёк обнаружит каждый аккаунт. Для стандартных аккаунтов Ginger основной сети native SegWit использует `m/84'/0'/0'`, а Taproot — `m/86'/0'/0'`. Углублённое восстановление в другом приложении должно поддерживать соответствующий аккаунт и тип адреса. По возможности выполняйте восстановление аппаратного кошелька на аппаратном устройстве.

Ginger не предлагает восстановление по долям SLIP39 в этой версии. Не вводите набор долей восстановления как один список слов BIP39.

## Импортируйте файл

Выберите **Import File** на экране добавления кошелька и укажите совместимый файл `.json`. Ginger может попросить другое имя, если такое уже используется. Случайный файл JSON, PSBT транзакции или произвольный xpub, вставленный в текстовый файл, не являются совместимой резервной копией кошелька.

Используйте исходную парольную фразу для открытия защищённого импортированного программного кошелька. Файл, зашифрованный через 2FA, не эквивалентен незашифрованной переносимой резервной копии. Сохраните его связанные файлы и учётные данные либо вместо этого восстановитесь по словам и исходной парольной фразе. Импорт аппаратного экспорта создаёт кошелёк, который по-прежнему зависит от устройства для подписания.

<span id="what-recovery-does-not-restore" data-ginger-heading="чего-восстановление-не-возвращает" aria-hidden="true"></span>

## Чего восстановление не возвращает

Блокчейн не может восстановить конфиденциальные метки, все настройки приложения или метаданные заказов поставщика. Сохраняйте соответствующий файл `.attr`, когда это важно. Не перезаписывайте недавно восстановленные файлы старыми метаданными, пока Ginger работает. Если вам нужна помощь в восстановлении сопутствующих данных, работайте с копиями и описывайте имена файлов и версию, не публикуя содержимое.

Храните оригиналы и работайте с копиями. Прочитайте [резервное копирование файлов кошелька](/ru/backup-recovery/backup-files/) перед изменением локальных данных.
