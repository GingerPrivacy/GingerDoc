**Secret Hunt** — функция Ginger, показывающая секреты событий, связанные с подходящей активностью CoinJoin. Она отделена от показателя приватности кошелька и обычной процедуры получения или расходования биткоина. Доступность событий зависит от сервиса; наличие функции не обещает текущего события, приза или награды.

<span id="view-and-control-participation" data-ginger-heading="просматривайте-участие-и-управляйте-им" aria-hidden="true"></span>

## Просматривайте участие и управляйте им

Откройте меню программного кошелька и выберите **Secret Hunt**. Диалог показывает результаты событий в виде дерева, включая обнаруженные слова или предложения и дополнительный секрет, когда собраны необходимые секреты события. Разверните событие, чтобы изучить его записи.

Используйте **Enable/disable the use of this wallet for Secret Hunt.**, чтобы управлять участием этого кошелька. В v2.0.27 Secret Hunt по умолчанию отключён для новых кошельков: включите его отдельно для каждого кошелька, с которым хотите участвовать. Существующие кошельки сохраняют настройку при обновлении, поэтому проверьте переключатель, если раньше использовали Secret Hunt.

Отключение очищает отображаемое дерево в отключённом представлении и прекращает выбор этого кошелька обновляющим компонентом для проверок права на участие в событиях. Оно не отменяет CoinJoin, не удаляет транзакции блокчейна и не стирает сведения, уже переданные сервису.

Этот пункт не предлагается для кошельков только для наблюдения. Он не является функцией CoinJoin аппаратного кошелька и не требует ввода слов восстановления на сайте события.

<span id="what-is-shared" data-ginger-heading="что-передаётся" aria-hidden="true"></span>

## Что передаётся

Клиент получает сведения событий из сервиса Ginger. Для проверки допуска он может отправлять идентификатор транзакции CoinJoin, ссылку на выбранный вход и криптографическое доказательство владения. Доказательство демонстрирует контроль для запроса события без передачи закрытого ключа. Это дополнительные раскрытия на уровне приложения, даже когда соединение использует Tor.

Tor решает вопрос раскрытия на сетевом уровне; он не убирает содержимое запроса от его получателя. Если вы не хотите использования кошелька для этих проверок событий, отключите его участие в Secret Hunt. Запросы списка событий и обычная сетевая активность кошелька отделены от этого переключателя для каждого кошелька.

<span id="missing-or-incomplete-results" data-ginger-heading="отсутствующие-или-неполные-результаты" aria-hidden="true"></span>

## Отсутствующие или неполные результаты

Результаты зависят от дат события, подходящей подтверждённой активности, доступности сервиса и периодических обновлений. Раунд может успешно завершиться без раскрытия нового секрета. Ожидание результатов не является свидетельством отсутствия биткоина.

Не создавайте дополнительные транзакции с комиссией в предположении, что награда компенсирует расходы. Прежде чем решать об участии, прочитайте фактические условия события через источник с подтверждённой подлинностью. Игнорируйте просьбы загрузить файл кошелька или отправить отдельную «комиссию получения» на адрес поддержки из нежелательного обращения.
