> Уровень: повседневное использование. Выберите это руководство, когда вам нужна описанная задача.

Используйте **Settings** для предпочтений всего приложения и **Wallet Settings** для имени, конфигурации CoinJoin и инструментов выбранного кошелька. Поиск приложения может находить действия вроде **Data Folder**, **Wallet Info** и **Discreet Mode**, не полагаясь на расположение значка.

<span id="language-and-amounts" data-ginger-heading="язык-и-суммы" aria-hidden="true"></span>

## Язык и суммы

В **Settings** → **Appearance** параметр **Language** выбирает язык интерфейса. Версия 2.0.26 предлагает английский, испанский, венгерский, французский, китайский, немецкий, португальский, турецкий и итальянский. Следуйте запросу перезапуска, если он появится. Исходное английское руководство использует английские названия выпущенной версии; переведённые названия могут отличаться.

**Dark mode** меняет внешний вид. **Exchange currency** меняет справочное отображение фиатной валюты, а десятичные разделители, разделители групп, группировка дробной части Bitcoin и **Fee display unit** управляют представлением чисел. Они не меняют основную сумму BTC или комиссию транзакции сети. Прочитайте примеры в настройках перед вводом суммы в незнакомом формате.

## Discreet Mode

Используйте **Discreet Mode**, когда кто-то может видеть экран. Он скрывает поддерживаемые чувствительные поля отображения, уменьшая случайное наблюдение. Перед демонстрацией экрана проверьте, что действительно скрыто: функция не гарантирует скрытия каждого диалога, адреса или внешнего приложения.

Discreet Mode не шифрует файлы, не блокирует кошелёк, не останавливает подписание и не меняет приватность блокчейна. Человек с доступом к компьютеру всё ещё может взаимодействовать с приложением. Когда отходите, используйте блокировку экрана операционной системы.

## Общие настройки

| Настройка | Практический эффект |
| --- | --- |
| **Run Ginger when computer starts** | Открывает Ginger вместе с сеансом операционной системы. |
| **Run in background when window closed** | Позволяет приложению оставаться активным после закрытия окна. Поэтому CoinJoin и синхронизация могут продолжаться. |
| **Auto copy addresses** | Может автоматически помещать отображаемый адрес в буфер обмена. |
| **Auto paste addresses** | Может использовать содержимое буфера обмена при вводе адресов. Всегда проверяйте получившееся назначение. |
| **Auto download new version** | Управляет загрузкой доступного обновления; отдельно следуйте запросу установки. |
| **Browser used by Ginger** | Выбирает браузер для внешних страниц; пользовательский вариант предоставляет **Custom browser path**. |

Удобство буфера обмена не подтверждает подлинность получателя. Другие приложения могут читать или заменять данные буфера. Никогда не помещайте слова восстановления в буфер обмена при обычном получении или отправке.

Внешние страницы используют собственное сетевое поведение и приватность выбранного браузера. Поставщик покупки/продажи может запрашивать идентификационные сведения, даже когда сам Ginger использует Tor. Изменение предпочтений отображения или браузера не меняет записи поставщика.

## Сведения и инструменты кошелька

**Wallet Info** может показывать сведения об аккаунте и расширенном открытом ключе. Расширенный открытый ключ не может непосредственно тратить монеты, но может раскрывать множество связанных адресов. Не публикуйте его в публичном запросе поддержки.

В **Wallet Settings** → **General** используйте элемент имени для переименования кошелька. В **Tools** элемент **Verify Recovery Words** проверяет резервную копию доступного программного кошелька, **Resync** перестраивает его представление данных, а **Delete Wallet** удаляет локальный кошелёк через процедуру подтверждения. Удаление не уничтожает биткоин, не отзывает слова восстановления и не заменяет резервную копию. Сохраняйте работающие сведения восстановления перед удалением локального доступа.
