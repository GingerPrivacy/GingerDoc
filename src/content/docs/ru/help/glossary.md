<span id="amounts-and-transactions" data-ginger-heading="суммы-и-транзакции" aria-hidden="true"></span>

## Суммы и транзакции

| Термин | Значение для пользователя кошелька |
| --- | --- |
| Bitcoin /ru/ BTC | Сеть и её денежная единица. Кошелёк управляет ключами и транзакциями, а не хранит физические монеты. |
| Сатоши /ru/ sat | Одна стомиллионная биткоина: 100,000,000 sats = 1 BTC. |
| Адрес | Назначение платежа, полученное из условий расходования. Используйте новый адрес для каждого поступления. |
| UTXO /ru/ монета | Неизрасходованный выход транзакции, который можно целиком потратить как вход. |
| Вход | Ссылка на предыдущий выход, который расходуется. Несколько входов могут финансировать одну транзакцию. |
| Выход | Новое назначение и стоимость, созданные транзакцией. |
| Сдача | Стоимость, возвращаемая в ваш кошелёк, когда выбранные входы превышают платёж вместе с комиссией. |
| Идентификатор транзакции /ru/ txid | Идентификатор транзакции. Передавая его, вы раскрываете, какую общедоступную транзакцию обсуждаете. |
| Мемпул | Набор неподтверждённых транзакций узла. У разных узлов могут быть разные представления этого набора. |
| Подтверждение | Включение в блок с последующим построением дополнительных блоков поверх него. |
| Ставка комиссии | Сатоши, уплачиваемые за виртуальный байт размера транзакции; отличается от полной комиссии. |
| vByte | Единица размера для сравнения ставок комиссий транзакций с разными данными witness. |
| RBF | Replace-by-fee: ожидающая транзакция может быть заменена согласно правилам узлов, обычно для повышения комиссии. |
| CPFP | Child-pays-for-parent: расходование выхода дочерней транзакцией с более высокой комиссией может стимулировать подтверждение и её неподтверждённой родительской транзакции. |
| Пыль | Сумма, слишком маленькая для полезного использования при определённых правилах или предположениях о стоимости. Порог кошелька и правила сети не обязательно одинаковы. |

<span id="the-network-in-context" data-ginger-heading="сеть-в-контексте" aria-hidden="true"></span>

## Сеть в контексте

| Термин | Значение для пользователя кошелька |
| --- | --- |
| Блок /ru/ блокчейн | Пакет транзакций и цепь блоков, продолжающая предыдущую историю. |
| Майнер /ru/ доказательство работы | Участник, собирающий блоки-кандидаты и выполняющий работу, используемую правилами выбора цепи Bitcoin. |
| Coinbase-транзакция | Первая транзакция блока, создающая допустимую награду за майнинг; она не связана с конкретной учётной записью биржи. Перед расходованием её выходы должны достичь зрелости. |
| Правила консенсуса | Правила, применяемые проверяющим узлом для определения корректности блоков и транзакций. |
| Сложность | Показатель, регулирующий доказательство работы, необходимое для блока; он не определяет баланс вашего кошелька. |
| Mainnet /ru/ RegTest | Настоящая сеть Bitcoin и отдельный локальный режим тестирования соответственно. Монеты не переходят между ними. |
| BIP | Bitcoin Improvement Proposal — документ с предложением стандарта или процесса. Публикация BIP не означает, что он реализован в каждом кошельке. |
| HD-кошелёк | Иерархический детерминированный кошелёк, получающий множество ключей из исходных секретных данных согласно определённым соглашениям. |
| Хеш | Компактный идентификатор, рассчитанный из данных. Идентификатор транзакции определяет данные, а не имя учётной записи человека. |
| Взаимозаменяемость | Практическая заменяемость единиц друг другом; сторонние классификации истории могут влиять на отношение к ним, даже если это корректные биткоины. |

Lightning, платёжные каналы, построение мультиподписных транзакций, настройка публичных testnet/Signet и внутреннее устройство скриптов выходят за рамки документированных пользовательских процедур этой версии. Наличие этих понятий в общем глоссарии Bitcoin не доказывает наличие соответствующей функции в Ginger.

<span id="keys-and-recovery" data-ginger-heading="ключи-и-восстановление" aria-hidden="true"></span>

## Ключи и восстановление

| Термин | Значение для пользователя кошелька |
| --- | --- |
| Закрытый ключ | Секретные сведения, разрешающие расходование. Никогда не передавайте их поддержке. |
| Открытый ключ | Сведения для проверки подписей; это не секрет для расходования, но он всё равно может быть чувствительным для конфиденциальности. |
| Слова восстановления /ru/ мнемоника /ru/ seed-фраза | Упорядоченная резервная копия слов, из которой можно воссоздать ключи кошелька с правильной парольной фразой и соглашениями кошелька. |
| Парольная фраза BIP39 | Дополнительный текст, используемый со словами восстановления для получения кошелька. Каждая отличающаяся парольная фраза выбирает другие ключи. |
| PIN устройства | Средство контроля доступа к аппаратному кошельку. Это не то же самое, что парольная фраза BIP39. |
| 2FA | Второй фактор аутентификации. Ginger использует аутентификатор и зависимое от сервиса шифрование локальных файлов кошелька при запуске. |
| xpub /ru/ расширенный открытый ключ | Сведения, позволяющие получить множество связанных публичных адресов. Он не может непосредственно подписывать, но может раскрыть активность кошелька. |
| Путь вывода /ru/ аккаунт | Соглашение, обозначающее ветвь ключей кошелька. Инструментам восстановления нужны совместимые соглашения. |
| Лимит промежутка | Последовательность неиспользованных адресов, которую сканирование восстановления допускает перед прекращением поиска вдоль ветви. |
| Кошелёк только для наблюдения | Запись кошелька, позволяющая наблюдать активность, но не содержащая локальных подписывающих ключей. Аппаратное устройство может предоставлять подпись отдельно. |
| Аппаратный кошелёк | Отдельное устройство, предназначенное для защиты ключей и одобрения поддерживаемых транзакций. |
| PSBT | Файл частично подписанной транзакции Bitcoin, содержащий предложенную транзакцию и сведения для подписания. |
| SegWit /ru/ Taproot | Форматы выходов и расходования Bitcoin. Нативные адреса получения основной сети обычно начинаются с `bc1q` и `bc1p` соответственно. |

<span id="privacy-and-ginger" data-ginger-heading="конфиденциальность-и-ginger" aria-hidden="true"></span>

## Конфиденциальность и Ginger

| Термин | Значение для пользователя кошелька |
| --- | --- |
| CoinJoin | Совместная транзакция с входами нескольких участников, предназначенная для усложнения выводов о связях владения. |
| WabiSabi | Протокол на основе удостоверений, используемый для координации CoinJoin в Ginger. Он не стирает транзакцию из блокчейна. |
| Координатор | Сервис, организующий раунд. Он может влиять на доступность и пригодность, обычно не владея закрытыми ключами участников. |
| Ремикс | Дальнейшее участие в CoinJoin со средствами, отвечающими условиям ремикса сервиса; комиссии майнерам могут сохраняться. |
| Оценка анонимности | Локальная оценка Ginger для классификации конфиденциальности монет, а не проверенное количество независимых людей. |
| Множество анонимности | Концептуальная группа правдоподобных альтернатив. Она не обязательно совпадает с рассчитанной оценкой кошелька. |
| Кластер | Адреса или монеты, которые наблюдатель считает принадлежащими одной группе. Некоторые связи являются фактами, другие — эвристиками, способными ошибаться. |
| Повторное использование адреса | Получение более одного раза на один адрес, которое непосредственно связывает эти поступления. |
| Контроль монет | Осознанное изучение и выбор монет для платежа. |
| Tor | Система сетевых ретрансляторов, помогающая отделить соединения приложения от IP-адреса пользователя. |
| Фильтр блоков | Компактное описание для выявления блоков, которые могут содержать транзакции кошелька, перед локальной обработкой этих блоков. |
| Полный узел | Программа, проверяющая данные Bitcoin по правилам консенсуса. Её роль отличается от роли координатора CoinJoin. |
| PayJoin | Совместный платёж, в котором получатель может внести вход. Выпущенная процедура отправки Ginger имеет запасной вариант и ограничения совместимости. |
| Discreet Mode | Скрытие поддерживаемых чувствительных полей на экране, а не шифрование или блокировка кошелька. |
| KYC | Процедура проверки личности у поставщика услуг. Tor не скрывает сведения, которые вы отправляете ему напрямую. |
| Фиат | Выпущенная государством валюта, используемая для котировок или отображаемых оценок; отличается от BTC, расчёт в которых производится в основной цепочке. |

Понятия «приватный» и «безопасный» описывают разные свойства. Спрашивайте, что защищено, от кого и при каких условиях, вместо того чтобы считать любое из этих слов безусловной гарантией.
