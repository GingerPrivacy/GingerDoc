## 金额与交易

| 术语 | 对钱包用户的含义 |
| --- | --- |
| 比特币 / BTC | 网络及其货币单位。钱包管理密钥和交易，而不是存储实物币。 |
| 聪 / sat | 一比特币的一亿分之一：100 000 000 聪 = 1 BTC。 |
| 地址 | 从花费条件派生的付款目的地。每次收款使用新地址。 |
| UTXO / 币 | 未花费交易输出，可作为完整输入花费。 |
| 输入 | 对正在花费的先前输出的引用。多个输入可为一笔交易提供资金。 |
| 输出 | 交易创建的新目的地和价值。 |
| 找零 | 所选输入超过付款加手续费时返回钱包的价值。 |
| 交易 ID / txid | 交易标识符。分享它会透露正在讨论哪笔公开交易。 |
| 内存池 | 节点保存的未确认交易集合。不同节点可能有不同视图。 |
| 确认 | 纳入一个区块，随后更多区块在其基础上继续构建。 |
| 手续费率 | 每虚拟字节交易大小支付的聪数；与总手续费不同。 |
| vByte | 虚拟字节，用于比较不同见证数据交易费率的大小单位。 |
| RBF | 手续费替换：节点策略允许替换待确认交易，常用于提高手续费。 |
| CPFP | 子为父付：用较高手续费子交易花费一个输出，可以促使其未确认父交易也确认。 |
| 粉尘 | 在特定策略或成本假设下过小而无实用价值的金额。钱包阈值与网络策略不一定相同。 |

<span id="the-network-in-context" data-ginger-heading="网络相关背景" aria-hidden="true"></span>

## 网络相关背景

| 术语 | 对钱包用户的含义 |
| --- | --- |
| 区块 / 区块链 | 一批交易，以及在此前历史上继续构建的区块链。 |
| 矿工 / 工作量证明 | 组装候选区块，并执行比特币链选择规则所用工作的参与者。 |
| Coinbase 交易 | 区块第一笔交易，创建允许的挖矿奖励；与特定交易所账户无关。其输出成熟后才可花费。 |
| 共识规则 | 验证节点用于判断区块和交易有效性的规则。 |
| 难度 | 决定区块所需工作量证明的度量；不决定钱包余额。 |
| Mainnet / RegTest | 分别是真实比特币主网和独立本地测试模式。币不会在两者之间移动。 |
| BIP | 比特币改进提案，记录拟议标准或流程。发布 BIP 不表示所有钱包实现它。 |
| HD 钱包 | 分层确定性钱包，根据初始秘密资料和约定派生许多密钥。 |
| 哈希 | 由数据计算的紧凑标识。交易 ID 标识数据，不是个人账户名称。 |
| 可互换性 | 单位实际上的可互换性质；第三方按历史分类可能影响其待遇，即使它们是有效比特币。 |

闪电网络、支付通道、多重签名构建、公开测试网/Signet 设置及脚本内部机制，不在本版本记录的最终用户流程范围内。它们出现在通用比特币术语表中，不代表 Ginger 提供相应功能。

## 密钥与恢复

| 术语 | 对钱包用户的含义 |
| --- | --- |
| 私钥 | 授权花费的秘密信息。切勿与客服分享。 |
| 公钥 | 用于验证签名的信息；不是花费秘密，但仍可能涉及隐私。 |
| 恢复助记词 / 助记词 / 种子短语 | 有序词语备份，配合正确口令和钱包约定可重新生成钱包密钥。 |
| BIP39 口令 | 与助记词一起派生钱包的额外文本。每个不同口令选择不同密钥。 |
| 设备 PIN | 硬件钱包访问控制，与 BIP39 口令不同。 |
| 2FA | 第二认证因素。Ginger 启动时使用身份验证器和依赖服务的本地钱包文件加密。 |
| xpub / 扩展公钥 | 可派生许多相关公开地址的信息。不能直接签名，但可暴露钱包活动。 |
| 派生路径 / 账户 | 标识钱包密钥分支的约定。恢复工具需要兼容约定。 |
| 地址间隔限制 | 恢复扫描沿分支搜索停止之前，允许连续出现的未使用地址数量。 |
| 仅观察钱包 | 可观察活动但没有本地签名密钥的钱包记录。硬件设备可另行提供签名。 |
| 硬件钱包 | 用于保护密钥并批准受支持交易的独立设备。 |
| PSBT | 部分签名比特币交易文件，包含提议交易和签名信息。 |
| SegWit / Taproot | 比特币输出和花费格式。主网原生收款地址通常分别以 `bc1q` 和 `bc1p` 开头。 |

<span id="privacy-and-ginger" data-ginger-heading="隐私与-ginger" aria-hidden="true"></span>

## 隐私与 Ginger

| 术语 | 对钱包用户的含义 |
| --- | --- |
| CoinJoin | 多个参与者提供输入的协作交易，旨在增加推断所有权关联的难度。 |
| WabiSabi | Ginger CoinJoin 协调使用的凭证协议。不会将交易从区块链抹去。 |
| 协调器 | 组织轮次的服务。通常不持有参与者私钥，但可影响可用性和资格。 |
| Remix | 使用符合服务再次参与条件的资金，进一步参与 CoinJoin；仍可能有矿工手续费。 |
| 匿名评分 | Ginger 用于分类币隐私的本地估计，不是经验证的独立人数。 |
| 匿名集 | 概念上的合理候选集合，不自动等同于钱包计算评分。 |
| 聚类 | 观察者推断属于同一组的地址或币。一些联系是事实，另一些是可能出错的启发式判断。 |
| 地址复用 | 同一地址多次收款，直接关联这些收款。 |
| 币控制 | 为付款有意识地查看和选择币。 |
| Tor | 通过网络中继帮助将应用连接与用户 IP 地址分隔的系统。 |
| 区块过滤器 | 紧凑摘要，用于在本地处理区块前识别可能包含钱包相关交易的区块。 |
| 全节点 | 按共识规则验证比特币数据的软件。与 CoinJoin 协调器角色不同。 |
| PayJoin | 收款人可提供输入的协作付款。Ginger 已发布发送流程有回退和兼容性限制。 |
| Discreet Mode | 隐藏受支持的敏感显示字段，不是加密或钱包锁定。 |
| KYC | 服务商的身份验证流程。Tor 不会隐藏直接提交的信息。 |
| 法币 | 政府发行货币，用于报价或显示估值；不同于链上结算的 BTC。 |

“私密”和“安全”等词描述不同性质。应询问保护什么、防范谁、在什么条件下成立，不要将任一词当作无条件保证。
