> 阅读级别：进阶指南。更改恢复或文件配置前，保留原始恢复信息和钱包文件。

复制本地钱包数据或调查备份保留哪些内容时，使用本参考。先阅读[基本备份指南](/zh-cn/backup-recovery/backups/)，了解每个软件钱包都需要的恢复信息。

<span id="what-to-keep" data-ginger-heading="应保留哪些内容" aria-hidden="true"></span>

## 应保留哪些内容

| 备份项目 | 用途 | 重要局限 |
| --- | --- | --- |
| 按顺序记录的助记词 | 重新生成钱包密钥 | 使用过口令时，需要原始口令 |
| 原始口令，包括大小写和所有字符 | 选择正确的 BIP39 钱包并解锁其受保护的秘密 | Ginger 无法重置 |
| 钱包 `.json` 文件 | 保留钱包存储的密钥和同步信息 | 加密文件仍需要凭证；2FA 可能增加服务依赖 |
| 对应的 `.attr` 文件 | 保留本地标签和钱包特有属性 | 含敏感元数据；助记词不能恢复它 |
| 硬件设备恢复备份 | 按硬件厂商流程恢复密钥 | 不要放在桌面电脑上 |

本地自动备份目录位于同一台电脑上。它可在钱包文件损坏后提供帮助，但不能防范整块磁盘丢失、盗窃或勒索软件。

<span id="make-a-file-backup" data-ginger-heading="制作文件备份" aria-hidden="true"></span>

## 制作文件备份

使用 Ginger 搜索打开 **Data Folder**。记下位置，再正常关闭 Ginger 后复制文件。在常规主网数据文件夹中，`Wallets` 包含钱包 `.json` 文件及关联 `.attr` 文件，`WalletBackups` 包含自动钱包备份。其他网络使用独立子目录。

将相关文件复制到受保护的备份存储中，保留文件名以及每个 JSON 和 ATTR 文件之间的对应关系。即使设置了口令，数据文件夹副本仍涉及隐私：地址、标签、日志、配置和订单元数据可能透露活动。不要上传到问题跟踪系统，也不要通过邮件发给客服。

启用 2FA 时，还要保留 `2fa_info.gws`，但不要将其误认为独立恢复密钥。它记录了与 Ginger 的 2FA 服务配合使用的标识符。通过助记词和原始口令恢复，仍是不依赖解密该特定本地钱包文件的途径。

<span id="choose-and-preserve-a-passphrase" data-ginger-heading="选择并保管口令" aria-hidden="true"></span>

## 选择并保管口令

选择他人难以猜到、且你能准确重现的口令。从明确的词表中随机选择词，或使用可信密码管理器生成的强密码，可避免姓名、日期、引用语和普通句子的可预测性。人手选择的“看似随机”替换通常比表面上更容易预测。

熵描述特定生成过程中的不可预测性；单凭长度不能确定熵。从大型词表中均匀随机选取的六个词，与从喜爱的歌词中选取的六个词，抗猜测能力不同。本手册不承诺某个字符数量能抵御所有攻击。

准确记录生成结果，并确认恢复计划保留了它。避免开头或结尾的空格：Ginger 的输入验证可能会删除或拒绝这些空格。密码管理器有助于保留强口令，但要规划同一台电脑丢失后如何访问管理器。将助记词和口令放在一起，会形成单点泄露风险；分开存储则增加恢复依赖。选择自己确实能够维护的安排。

对于 Ginger 软件钱包，口令也保护存储的加密秘密。因此，不能假定文件盗窃者或恢复操作没有口令也能成功。不要随意在其他钱包应用中更改口令：不同的 BIP39 口令选择不同密钥，而不是仅仅修改旧钱包的登录密码。

关于账户兼容性、文件导入或扫描遗漏地址的问题，使用[进阶恢复选项](/zh-cn/backup-recovery/recovery-options/)。

<span id="a-single-private-key-is-not-the-full-recovery-backup" data-ginger-heading="单个私钥不是完整恢复备份" aria-hidden="true"></span>

## 单个私钥不是完整恢复备份

如果实物币的制作者生成了密钥并预先充值，就需要相信其没有保留密钥。打印的单个私钥或厂商提供的秘密，不是 Ginger 的完整助记词备份。保留软件钱包的助记词和原始口令，不要认为一个导出的密钥涵盖所有地址。
