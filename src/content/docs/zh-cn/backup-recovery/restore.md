> 阅读级别：日常使用。需要完成本指南所述任务时，选择此页。

恢复是查找密钥及其交易历史的过程。开始之前，如果还能访问旧电脑，请保存其钱包文件。使用副本操作，并在验证恢复的钱包之前保留原件。

<span id="recover-from-words" data-ginger-heading="通过助记词恢复" aria-hidden="true"></span>

## 通过助记词恢复

1. 在可信电脑上安装并验证 Ginger。在添加钱包页面选择 **Recover**。
2. 按提示填写 **Wallet Name**。使用不同名称，避免与现有钱包混淆。
3. 按顺序输入原始助记词。使用实际备份，不要使用新生成的一组词。
4. 在 **Enter Passphrase** 中输入创建原始钱包时使用的口令。仅当原钱包没有口令时留空。此处不是设置替代密码。
5. 等待同步和恢复完成。核对已知交易和收款地址，不要只看显示的法币价值。恢复期间，一些常规钱包操作会被隐藏。

不同口令会派生出不同的有效钱包。因此，输入错误可能生成空钱包，而在种子恢复过程中不会出现“口令错误”提示。在认定资金消失前，检查大小写、空格、键盘布局和原始备份。

<span id="an-apparently-empty-recovered-wallet" data-ginger-heading="恢复的钱包看起来是空的" aria-hidden="true"></span>

## 恢复的钱包看起来是空的

首先检查是否选中了目标钱包和网络。主网和测试网络的币互不相同。然后检查连接及恢复进度。若应用仍在搜索，不完整余额不是最终结果。

如果上述检查都正确，但已知交易仍缺失，不要随机更改设置。用其他应用创建的钱包，或有大量未使用地址的钱包，可能需要更有针对性的调查。

可选进阶参考：[账户、地址扫描与文件导入](/zh-cn/backup-recovery/recovery-options/)。它涵盖这些情况，但不会把自定义恢复设置作为常规助记词恢复的必要步骤。

通过助记词恢复可以重新访问对应密钥。私密标签和其他本地记录可能需要单独的文件备份。

<span id="if-something-is-missing" data-ginger-heading="如果缺少某些内容" aria-hidden="true"></span>

## 如果缺少某些内容

| 仍然持有的内容 | 实际下一步 |
| --- | --- |
| 助记词和原始口令 | 在可信安装环境中恢复 |
| 可访问的钱包，但助记词缺失或无效 | 趁仍能访问时，创建已备份的新钱包并转移资金 |
| 钱包文件及其原始凭证 | 尝试导入副本；保留所有配套文件 |
| 助记词，但忘记了非空口令 | Ginger 无法重置；不要把恢复出的空钱包误认为恢复成功 |
| 硬件设备，但没有可靠备份 | 在冒险操作设备前，按厂商流程检查备份 |
| 既不能花费，也没有可用恢复信息 | 客服无法凭空生成缺失的密钥 |

切勿向“恢复助手”提供助记词、口令、私钥或钱包文件。正规诊断会从应用版本、网络和错误文本等非秘密信息开始。
