比特币交易公开，但钱包所有者姓名不会自动写在每个地址旁边。实际问题是谁能将地址或交易与你联系，以及从这种联系还能推断什么。

客户可能知道你在账单上提供的比特币收款地址。交易所可能知道提现地址和已验证身份。追踪公开捐款地址的人可以观察收款。这些观察者起始信息不同，所以把隐私理解为控制披露，比单一的匿名/不匿名开关更有用。

<span id="what-the-blockchain-reveals" data-ginger-heading="区块链透露什么" aria-hidden="true"></span>

## 区块链透露什么

交易显示输入、输出、价值及通过花费建立的关系。一个输出之后被另一笔交易花费，会形成公开联系。这不会自动证明每个输出归谁：交易可能是付款、自己钱包之间转账，或多个所有者的协作交易。原始[比特币论文的隐私部分](https://bitcoin.org/bitcoin.pdf)讨论公开交易与身份的分离，以及密钥关联问题。

有人将地址与某人关联后，就能调查相关活动。有些联系是直接的，例如反复向同一地址付款。其他联系依赖共同输入所有权或哪个输出是找零等假设。这些假设可能错误，但仍可能影响服务如何分类交易。

<span id="who-can-learn-what" data-ginger-heading="谁能知道什么" aria-hidden="true"></span>

## 谁能知道什么？

| 观察者 | 可能起始掌握的信息 | 你能控制什么 |
| --- | --- | --- |
| 付款人 | 你提供的地址及其付款 | 每次收款提供新地址 |
| 收款人 | 你的付款交易和购买信息 | 检查选中输入，避免不必要身份披露 |
| 交易所或购买服务商 | 账户记录、付款详情、存入/提现地址 | 使用前了解服务商记录 |
| 公开区块链分析者 | 交易数据及从别处取得的标签 | 避免建立易识别关联；评估 CoinJoin 和后续花费习惯 |
| 联系的网络服务 | 请求内容及可能的连接元数据 | 支持时保持 Tor 开启，了解特定功能披露 |
| 能访问电脑或备份的人 | 钱包文件、标签、地址、日志，可能还有密钥 | 保护设备、恢复备份和本地元数据 |

没有一个钱包设置能处理每一行。硬件钱包帮助保护密钥，但不隐藏公开地址。Tor 帮助保护连接元数据，但不隐藏输入到服务商表单的信息。

<span id="why-this-matters-in-ordinary-life" data-ginger-heading="为什么与日常生活有关" aria-hidden="true"></span>

## 为什么与日常生活有关

向多个客户提供同一账单收款地址时，每个客户都能看到发往该地址的收款，包括其他客户付款。新地址可避免直接共享同一标识符，但若之后把所有收款一起花费，不会自动防止后续关联。

从与公开捐款活动关联的资金付款，交易可能透露比付款金额更多的背景。记录哪些币属于哪种活动，可在花费前作出知情选择。

金融隐私可保护客户机密、商业信息、私人关系和人身安全。希望有这些边界不需要做错过什么。相关问题是，完成互动是否需要让对方接触这些信息。

<span id="privacy-and-fungibility" data-ginger-heading="隐私与可互换性" aria-hidden="true"></span>

## 隐私与可互换性

可互换性意味着单位可按等价条件交换。比特币交易规则核算价值，但个人和服务可以根据表面历史，对输出作不同分类。即使输出符合比特币规则，这些判断仍可能造成阻碍。

隐私工具能使某些历史分类更难可靠确定，却不能要求服务商接受转账，或抹去其已有记录。谨慎看待“干净”币或保证接受的说法：钱包隐私估计和服务政策是两回事。

<span id="where-ginger-fits" data-ginger-heading="ginger-的作用" aria-hidden="true"></span>

## Ginger 的作用

Ginger 提供新地址收款、本地标签、币控制、Tor 集成、紧凑过滤器钱包同步和 CoinJoin。这些工具可减少特定披露，并在授权前检查付款。桌面版也支持用于密钥保护的硬件钱包流程。

先使用新地址收款，并了解现有币。如果关心交易关联隐私，在启用自动轮次前，学习 CoinJoin 能与不能改变的内容。日常选择继续阅读[付款前后的隐私习惯](/zh-cn/using-ginger/address-reuse/)。

目标是有意识地改善自己的情况。Ginger 不能抹去交易所已收集的信息、承诺所有服务都接受资金，或防止日后自愿披露建立新关联。
