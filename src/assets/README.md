The Ginger emblem comes from the official [GingerWallet desktop assets](https://github.com/GingerPrivacy/GingerWallet/tree/c7e591db5dc9048b48bbf882372bd277f9e6271e/WalletWasabi.Fluent.Desktop/Assets).

`public/ginger-icon.png` is the unchanged `WasabiLogo256.png`. `public/favicon.ico` packages the unchanged 16, 24, 32, 48 and 256 pixel PNG assets into an ICO container. The names in the source repository still use the Wasabi prefix.

`logo.svg` embeds the same 256 pixel PNG beside the existing vector wordmark. When updating the brand icon, update both the public image and the embedded image so the header and bookmarks stay consistent.
